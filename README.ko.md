# Proxion

**정말로 당신의 것이 되는 프라이빗 메신저.**

진짜 종단 간 암호화를 갖춘 채팅, 음성, 영상. 대화는 회사의 서버가 아니라 당신이 관리하는
저장소에 저장됩니다. 개방형 [Solid](https://solidproject.org) 표준 위에 구축되었습니다.
전화번호도, 가입도, 중간에 끼어드는 회사도 없습니다.

## Proxion이란?

Proxion은 당신이 이미 쓰고 있는 것과 비슷한 메신저이지만, 모든 것을 바꾸는 한 가지 차이가
있습니다. 당신의 데이터는 당신의 것입니다.

메시지, 파일, 통화 기록은 회사 앱 안에 갇히는 대신 당신이 관리하는 개인 저장 공간인 당신만의
**Solid 팟**에 저장됩니다. 무료 팟 제공자를 고르거나, 직접 가져오거나, 스스로 호스팅하고,
언제든 옮길 수 있습니다. 당신의 신원은 당신 기기에서 만들어지므로 가입할 계정도 없고 유출될
것도 없습니다.

이것은 실제 일상용 메신저입니다. 방과 다이렉트 메시지, 화면 공유가 되는 음성 및 영상 통화,
파일, 반응, 답장 등을 Windows, macOS, Linux, 그리고 웹에서 사용할 수 있습니다.

## Proxion 받기

**내려받아 열기만 하면 됩니다.** 설정할 것도, 실행할 서버도 없습니다.

- **Windows, macOS 또는 Linux:** [설치 페이지](https://cafetechne.github.io/proxion-messenger/)
  또는 [최신 릴리스](../../releases/latest)를 받으세요.
- **[Homebrew](https://brew.sh)를 쓰는 macOS:** `brew install cafeTechne/proxion/proxion`
- **브라우저에서:** Proxion은 설치 가능한 웹 앱으로도 실행됩니다.

Proxion은 Apple이나 Microsoft의 서명을 받지 않았기 때문에(당신과 당신의 소프트웨어 사이에
아무런 문지기도 두지 않으려는 의도적인 선택입니다), 처음 열 때 운영체제가 한 번만 경고를
표시합니다. Windows에서는 *추가 정보 후 실행*을, macOS에서는 *마우스 오른쪽 클릭 후 열기*를
선택하세요. Linux에서는 아무 경고도 없습니다.

## 할 수 있는 것

- **메시지와 통화.** 그룹 방과 비공개 일대일 채팅, 그리고 화면 공유가 되는 피어 투 피어 음성
  및 영상 통화.
- **기록 보관.** 모든 것이 개방형 형식으로 당신의 팟에 저장되므로, 보관하고 다른 도구로 읽고
  가지고 다닐 수 있습니다.
- **정말로 비공개인 대화.** 다이렉트 메시지는 종단 간 암호화되며, 함께 소리 내어 읽는 짧은
  보안 문구로 정말로 상대와 이야기하고 있음을 확인할 수 있습니다. 통화도 같은 방식으로 암호화
  됩니다.
- **Solid의 누구에게나 연결.** Proxion 사용자뿐 아니라 더 넓은 Solid 생태계의 사람들을 찾아
  초대할 수 있습니다.
- **어디서나 사용.** 데스크톱, 브라우저, 모바일, 오프라인 지원, 오른쪽에서 왼쪽으로 쓰는
  아랍어를 포함한 6개 언어, 그리고 스크린 리더와 키보드만으로도 작동하도록 만들어졌습니다.

## Solid 생태계의 일부

Proxion은 내부에서 Solid를 쓰기만 하는 담장 친 정원이 아니라, 좋은 Solid 시민입니다. 당신이
만드는 방은 표준 Solid 채팅 형식으로 기록되므로 다른 Solid 앱이 읽고 참여할 수 있습니다.

<img src="landing/assets/interop-sidebyside.png" alt="Proxion과 SolidOS 데이터브라우저에 나란히 표시된 같은 방, 같은 메시지" width="900">

- **[SolidOS](https://solidos.org)에서 Proxion 방 열기**, 그러면 모든 메시지가 그대로
  있습니다. 이것은 주장이 아니라 우리 테스트에서 실제 SolidOS를 상대로 검증됩니다.
- **WebID로 사람 찾고 초대하기.** 누군가 호스팅하는 방을 발견하거나, 어떤 Solid 앱이든 읽을
  수 있는 초대를 그 사람의 Solid 편지함에 넣으세요.
- **새 메시지와 초대를 실시간으로,** Proxion이 닫혀 있어도 도착합니다.
- **당신의 방은 어떤 서버보다 오래갑니다.** 방의 구조가 당신의 팟에 저장되므로 팟만으로 다시
  만들 수 있습니다.

공유 방은 다른 앱이 읽을 수 있도록 설계상 열려 있습니다. 비공개 다이렉트 메시지는 종단 간
암호화되며 의도적으로 그 참여자만 읽을 수 있습니다. 전체 데이터 형식은
[docs/POD_DATA_MODEL.md](docs/POD_DATA_MODEL.md)에, 앱별 호환성은
[docs/INTEROP.md](docs/INTEROP.md)에, Solid 사양 모음에 대한 요구사항별 감사는
[docs/SOLID_COMPLIANCE.md](docs/SOLID_COMPLIANCE.md)에 문서화되어 있습니다.

## 설계부터 비공개

- **종단 간 암호화된** 다이렉트 메시지와 통화, 그래서 중간의 어떤 릴레이나 서버도 읽을 수
  없습니다.
- **당신의 데이터는 당신의 팟에, 공개된 형태로.** 잠긴 덩어리가 아니라 문서화된 표준 데이터
  이므로 당신이 허락한 어떤 앱이든 읽을 수 있고 언제든 떠날 수 있습니다.
- **약속이 아니라 검증 가능.** 모든 내려받기는 이 공개 소스 코드까지 거슬러 확인할 수 있고,
  변경마다 수천 개의 자동 테스트가 실행됩니다.

통화 보안 모델, 위협 모델, 내려받기 검증 방법을 포함한 자세한 내용은
[docs/SECURITY-MODEL.md](docs/SECURITY-MODEL.md), [docs/CALLS.md](docs/CALLS.md),
[SECURITY.md](SECURITY.md), [docs/VERIFYING.md](docs/VERIFYING.md)를 보세요.

## 기여하기

Proxion은 오픈 소스이며 버그 신고부터 코드까지 기여를 진심으로 환영합니다.
[CONTRIBUTING.md](CONTRIBUTING.md)에서 시작하세요. Solid 커뮤니티에서 오셨고 무언가가 기대한
대로 상호운용되지 않는다면, 그것이야말로 우리가 듣고 싶은 종류의 문제입니다.

## 개발자와 자체 호스팅 사용자를 위해

대부분의 사람은 위의 설치 프로그램만 쓰면 됩니다. Proxion을 손보거나 항상 켜져 있는 자체
게이트웨이를 실행하려면(예: 휴대폰을 데스크톱에 연결하려면):

```bash
pip install -e ./proxion-messenger-core[gateway]
cp .env.example .env   # 선택적 팟 자격 증명; 로컬 전용이면 비워 두세요
python run_gateway.py
# http://localhost:8080 열기
```

네이티브 설치 프로그램 빌드:

```bash
pip install pyinstaller
pip install -e ./proxion-messenger-core[gateway]
python build_sidecar.py           # 당신의 플랫폼용으로 게이트웨이 번들
cd tauri-app && cargo tauri build # 네이티브 설치 프로그램
```

테스트 실행:

```bash
cd proxion-messenger-core && pytest    # 백엔드
cd web && npm test                     # 프론트엔드
```

**어떻게 맞물리는가.** 프런트엔드(`web/` 안)는 당신의 키를 보관하고 팟과 통신하며 연락처의
게이트웨이에 직접 연결하는 작은 **게이트웨이**(`proxion-messenger-core/` 안)가 제공합니다.
데스크톱에서는 게이트웨이가 앱 안에 번들되어 함께 시작되므로 당신은 그것을 보지도, Python을
설치하지도 않습니다. 게이트웨이가 존재하는 이유는 Solid가 데이터와 신원은 다루지만 실시간
전달, 접속 상태, 통화 설정은 다루지 않기 때문이며, 이는 Matrix의 홈서버나 이메일의 SMTP
서버와 같은 역할입니다. 자세한 내용은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)와
[docs/SELF_HOSTING.md](docs/SELF_HOSTING.md)에 있습니다.
