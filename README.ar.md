# Proxion

**مراسلة خاصة تملكها فعلاً.**

دردشة وصوت وفيديو بتشفير حقيقي من طرف إلى طرف، حيث تعيش محادثاتك في مساحة تخزين تتحكم بها أنت
بدلاً من خوادم شركة ما. مبني على معيار [Solid](https://solidproject.org) المفتوح. بلا رقم هاتف،
وبلا تسجيل، وبلا أي شركة في المنتصف.

## ما هو Proxion؟

Proxion مراسِل مثل الذي تستخدمه بالفعل، لكن بفارق واحد يغيّر كل شيء: بياناتك ملك لك.

رسائلك وملفاتك وسجل مكالماتك تعيش في **بود Solid** الخاص بك، وهو مساحة تخزين شخصية تتحكم بها،
بدلاً من أن تكون محبوسة داخل تطبيق شركة. اختر مزوّد بود مجانياً، أو أحضر بودك الخاص، أو استضفه
بنفسك، وانتقل متى شئت. تُنشأ هويتك على جهازك، لذا لا يوجد حساب لتسجيله ولا شيء يمكن أن يتسرب.

إنه مراسِل حقيقي للاستخدام اليومي: غرف ورسائل مباشرة، ومكالمات صوتية ومرئية مع مشاركة الشاشة،
وملفات وتفاعلات وردود والمزيد، على Windows وmacOS وLinux والويب.

## احصل على Proxion

**نزّله وافتحه.** لا شيء لإعداده ولا خادم لتشغيله.

- **Windows أو macOS أو Linux:** توجّه إلى [صفحة التثبيت](https://cafetechne.github.io/proxion-messenger/)
  أو [أحدث إصدار](../../releases/latest).
- **macOS مع [Homebrew](https://brew.sh):** `brew install cafeTechne/proxion/proxion`
- **في متصفحك:** يعمل Proxion أيضاً كتطبيق ويب قابل للتثبيت.

بما أن Proxion غير موقّع من Apple أو Microsoft (عن قصد، حتى لا يقف أي حارس بينك وبين برنامجك
الخاص)، يعرض نظامك تنبيهاً لمرة واحدة عند أول فتح له. على Windows اختر *مزيد من المعلومات ثم
التشغيل على أي حال*؛ وعلى macOS *انقر بزر الفأرة الأيمن ثم افتح*؛ ولا يعرض Linux أي تنبيه.

## ما الذي يمكنك فعله

- **راسِل واتصل.** غرف جماعية ودردشات خاصة فردية، إضافة إلى مكالمات صوتية ومرئية ندّاً لندّ مع
  مشاركة الشاشة.
- **احتفظ بسجلّك.** كل شيء يعيش في بودك، بصيغة مفتوحة، فهو ملك لك: تحتفظ به، وتقرؤه بأدوات أخرى،
  وتأخذه معك.
- **محادثات خاصة فعلاً.** الرسائل المباشرة مشفّرة من طرف إلى طرف، ويمكنك التأكد من أنك تحدّث جهة
  اتصالك حقاً عبر عبارة أمان قصيرة تقرآنها بصوت عالٍ معاً. والمكالمات مشفّرة بالطريقة نفسها.
- **تواصل مع أي شخص على Solid.** اعثر على أشخاص من منظومة Solid الأوسع وادعُهم، لا مستخدمي
  Proxion وحدهم.
- **استخدمه في أي مكان.** سطح المكتب والمتصفح والهاتف، بقدرة على العمل دون اتصال، وبستّ لغات
  منها العربية من اليمين إلى اليسار، ومصمَّم للعمل بقارئ الشاشة ولوحة المفاتيح وحدهما.

## جزء من منظومة Solid

Proxion مواطن Solid صالح، لا حديقة مسوّرة تستخدم Solid في الخفاء فحسب. الغرفة التي تنشئها تُكتب
بصيغة الدردشة المعيارية في Solid، فتستطيع تطبيقات Solid الأخرى قراءتها والانضمام إليها.

<img src="landing/assets/interop-sidebyside.png" alt="الغرفة نفسها معروضة جنباً إلى جنب في Proxion وفي متصفح بيانات SolidOS، بالرسائل نفسها" width="900">

- **افتح غرفة Proxion في [SolidOS](https://solidos.org)** وستجد كل رسالة فيها. هذا مُتحقَّق منه
  مقابل SolidOS الحقيقي في اختباراتنا، وليس مجرد ادعاء.
- **اعثر على أشخاص وادعُهم عبر WebID الخاص بهم.** اكتشف الغرف التي يستضيفها شخص ما، أو ضع دعوة
  في صندوق وارد Solid الخاص به يمكن لأي تطبيق Solid قراءتها.
- **شاهد الرسائل والدعوات الجديدة فورياً،** بل وتصلك حتى عندما يكون Proxion مغلقاً.
- **غرفك تبقى بعد أي خادم بعينه.** بنية الغرفة تعيش في بودك، فيمكن إعادة بنائها من بودك وحده.

الغرف المشتركة مفتوحة بحكم التصميم كي تقرأها التطبيقات الأخرى؛ أما الرسائل المباشرة الخاصة
فمشفّرة من طرف إلى طرف وقابلة للقراءة عمداً من المشاركين فيها وحدهم. صيغة البيانات الكاملة موثّقة
في [docs/POD_DATA_MODEL.md](docs/POD_DATA_MODEL.md)، وصورة التوافق تطبيقاً تطبيقاً في
[docs/INTEROP.md](docs/INTEROP.md)، وتدقيق مطلباً مطلباً مقابل مجموعة مواصفات Solid في
[docs/SOLID_COMPLIANCE.md](docs/SOLID_COMPLIANCE.md).

## خاص بحكم التصميم

- **رسائل مباشرة ومكالمات مشفّرة من طرف إلى طرف،** بحيث لا يستطيع أي مُرحِّل أو خادم في المنتصف
  قراءتها.
- **بياناتك في بودك، في العلن.** إنها بيانات موثّقة ومعيارية، لا كتلة مقفلة، فيمكن لأي تطبيق
  تسمح له بقراءتها، ويمكنك المغادرة متى شئت.
- **قابل للتحقق، لا موعود به فقط.** يمكن تتبّع كل تنزيل رجوعاً إلى شيفرة المصدر العلنية هذه،
  وتُشغَّل آلاف الاختبارات الآلية مع كل تغيير.

للتفاصيل، بما فيها نموذج أمان المكالمات ونموذج التهديد وكيفية التحقق من تنزيل، انظر
[docs/SECURITY-MODEL.md](docs/SECURITY-MODEL.md) و[docs/CALLS.md](docs/CALLS.md) و
[SECURITY.md](SECURITY.md) و[docs/VERIFYING.md](docs/VERIFYING.md).

## المساهمة

Proxion مفتوح المصدر والمساهمات مُرحَّب بها حقاً، من تقارير الأخطاء إلى الشيفرة. ابدأ بـ
[CONTRIBUTING.md](CONTRIBUTING.md). وإن كنت قادماً من مجتمع Solid ووجدت شيئاً لا يتوافق كما
تتوقع، فهذا بالضبط نوع المشكلات التي نودّ سماعها.

## للمطورين ومن يستضيفون ذاتياً

معظم الناس ينبغي أن يكتفوا بالمثبِّت أعلاه. للعبث بـ Proxion أو تشغيل بوابتك الخاصة الدائمة
(مثلاً لتوجيه هاتف إلى سطح مكتبك):

```bash
pip install -e ./proxion-messenger-core[gateway]
cp .env.example .env   # optional pod credentials; leave blank for local-only
python run_gateway.py
# open http://localhost:8080
```

ابنِ مثبِّتاً أصلياً:

```bash
pip install pyinstaller
pip install -e ./proxion-messenger-core[gateway]
python build_sidecar.py           # bundle the gateway for your platform
cd tauri-app && cargo tauri build # native installer
```

شغّل الاختبارات:

```bash
cd proxion-messenger-core && pytest    # backend
cd web && npm test                     # frontend
```

**كيف يترابط كل شيء.** الواجهة الأمامية (في `web/`) تخدمها **بوابة** صغيرة (في
`proxion-messenger-core/`) تحفظ مفاتيحك، وتتحدث إلى بودك، وتتصل مباشرة ببوابات جهات اتصالك. على
سطح المكتب تكون البوابة مضمّنة داخل التطبيق وتبدأ معه، فلا تراها أبداً ولا تثبّت Python. البوابة
موجودة لأن Solid يغطي البيانات والهوية لكن لا يغطي التسليم الحيّ ولا الحضور ولا إعداد المكالمات،
وهو الدور نفسه الذي يؤديه homeserver في Matrix أو خادم SMTP للبريد. التفاصيل في
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) و[docs/SELF_HOSTING.md](docs/SELF_HOSTING.md).
