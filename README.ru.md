# Proxion

**Приватные сообщения, которые действительно принадлежат вам.**

Чат, голос и видео с настоящим сквозным шифрованием, где ваши разговоры хранятся в хранилище,
которым управляете вы, а не на серверах компании. Построено на открытом стандарте
[Solid](https://solidproject.org). Без номера телефона, без регистрации, без компании
посередине.

## Что такое Proxion?

Proxion работает как привычный вам мессенджер, но с одним отличием, которое меняет всё: ваши
данные принадлежат вам.

Ваши сообщения, файлы и история звонков хранятся в вашем собственном **pod Solid**, личном
хранилище, которым управляете вы, а не заперты внутри приложения компании. Выберите бесплатного
поставщика pod, подключите свой или разместите его сами, и переезжайте когда угодно. Ваша
личность создаётся на вашем устройстве, поэтому нет учётной записи для регистрации и нечему
утекать.

Это настоящий повседневный мессенджер: комнаты и личные сообщения, голосовые и видеозвонки с
демонстрацией экрана, файлы, реакции, ответы и не только, на Windows, macOS, Linux и в вебе.

## Как получить Proxion

**Скачайте и откройте.** Ничего не нужно настраивать, и не нужно запускать сервер.

- **Windows, macOS или Linux:** откройте [страницу установки](https://cafetechne.github.io/proxion-messenger/)
  или [последний выпуск](../../releases/latest).
- **macOS с [Homebrew](https://brew.sh):** `brew install cafeTechne/proxion/proxion`
- **В браузере:** Proxion также работает как устанавливаемое веб-приложение.

Поскольку Proxion не подписан Apple или Microsoft (намеренно, чтобы между вами и вашим
собственным ПО не стоял никакой привратник), при первом запуске система показывает одноразовое
предупреждение. В Windows выберите *Подробнее, затем Выполнить в любом случае*; в macOS
*щёлкните правой кнопкой, затем Открыть*; в Linux предупреждения нет.

## Что вы можете делать

- **Пишите и звоните.** Групповые комнаты и приватные чаты один на один, а также одноранговые
  голосовые и видеозвонки с демонстрацией экрана.
- **Храните свою историю.** Всё лежит в вашем pod, в открытом формате, поэтому она ваша: храните
  её, читайте другими инструментами и забирайте с собой.
- **По-настоящему приватные разговоры.** Личные сообщения защищены сквозным шифрованием, и вы
  можете убедиться, что действительно говорите со своим контактом, с помощью короткой фразы
  безопасности, которую вы вместе читаете вслух. Звонки шифруются так же.
- **Достучитесь до любого в Solid.** Находите и приглашайте людей из всей экосистемы Solid, а не
  только других пользователей Proxion.
- **Пользуйтесь где угодно.** Компьютер, браузер и телефон, с работой офлайн, на 16 языках,
  включая арабский справа налево, и сделано так, чтобы работать с одним лишь скринридером и
  клавиатурой.

## Часть экосистемы Solid

Proxion ведёт себя как добропорядочный гражданин Solid, а не как огороженный сад, который лишь
использует Solid внутри. Комната, которую вы создаёте, записывается в стандартном формате чата
Solid, поэтому другие приложения Solid могут её читать и присоединяться к ней.

<img src="landing/assets/interop-sidebyside.png" alt="Одна и та же комната показана рядом в Proxion и в браузере данных SolidOS, с одинаковыми сообщениями" width="900">

- **Откройте комнату Proxion в [SolidOS](https://solidos.org)**, и каждое сообщение на месте.
  Это проверяется в наших тестах против настоящего SolidOS, а не просто заявляется.
- **Находите и приглашайте людей по их WebID.** Обнаруживайте комнаты, которые кто-то размещает,
  или оставьте приглашение в его Solid-ящике, которое может прочитать любое приложение Solid.
- **Видьте новые сообщения и приглашения в реальном времени,** они доходят до вас даже когда
  Proxion закрыт.
- **Ваши комнаты переживут любой отдельный сервер.** Структура комнаты хранится в вашем pod,
  поэтому её можно восстановить из одного лишь вашего pod.

Общие комнаты открыты по замыслу, чтобы другие приложения могли их читать; приватные личные
сообщения защищены сквозным шифрованием и намеренно читаемы только участниками. Полный формат
данных описан в [docs/POD_DATA_MODEL.md](docs/POD_DATA_MODEL.md), картина совместимости по
каждому приложению в [docs/INTEROP.md](docs/INTEROP.md), а проверка по каждому требованию
относительно набора спецификаций Solid в [docs/SOLID_COMPLIANCE.md](docs/SOLID_COMPLIANCE.md).

## Приватность по замыслу

- **Личные сообщения и звонки со сквозным шифрованием,** так что никакой ретранслятор или сервер
  посередине не может их прочитать.
- **Ваши данные в вашем pod, открыто.** Это документированные стандартные данные, а не запертый
  блоб, поэтому любое приложение, которому вы разрешите, может их прочитать, а вы можете уйти в
  любой момент.
- **Проверяемо, а не просто обещано.** Каждую загрузку можно проследить до этого открытого
  исходного кода, и при каждом изменении выполняются тысячи автоматических тестов.

Подробности, включая модель безопасности звонков, модель угроз и способ проверки загрузки,
смотрите в [docs/SECURITY-MODEL.md](docs/SECURITY-MODEL.md), [docs/CALLS.md](docs/CALLS.md),
[SECURITY.md](SECURITY.md) и [docs/VERIFYING.md](docs/VERIFYING.md).

## Как внести вклад

Proxion имеет открытый исходный код, и вклады действительно приветствуются, от сообщений об
ошибках до кода. Начните с [CONTRIBUTING.md](CONTRIBUTING.md). Если вы пришли из сообщества
Solid и что-то не взаимодействует так, как вы ожидаете, это именно тот случай, о котором мы
хотим услышать.

## Для разработчиков и тех, кто размещает сам

Большинству достаточно просто использовать установщик выше. Чтобы поковыряться в Proxion или
запустить свой постоянно работающий шлюз (например, чтобы направить телефон на свой компьютер):

```bash
pip install -e ./proxion-messenger-core[gateway]
cp .env.example .env   # необязательные учётные данные pod; оставьте пустым для локального режима
python run_gateway.py
# откройте http://localhost:8080
```

Собрать нативный установщик:

```bash
pip install pyinstaller
pip install -e ./proxion-messenger-core[gateway]
python build_sidecar.py           # упаковать шлюз для вашей платформы
cd tauri-app && cargo tauri build # нативный установщик
```

Запустить тесты:

```bash
cd proxion-messenger-core && pytest    # бэкенд
cd web && npm test                     # фронтенд
```

**Как всё устроено.** Фронтенд (в `web/`) обслуживается небольшим **шлюзом** (в
`proxion-messenger-core/`), который хранит ваши ключи, общается с вашим pod и напрямую
соединяется со шлюзами ваших контактов. На компьютере шлюз встроен в приложение и запускается
вместе с ним, поэтому вы никогда его не видите и не устанавливаете Python. Шлюз существует
потому, что Solid покрывает данные и личность, но не живую доставку, присутствие или
установление звонков, ту же роль играет homeserver для Matrix или сервер SMTP для электронной
почты. Подробности в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) и
[docs/SELF_HOSTING.md](docs/SELF_HOSTING.md).
